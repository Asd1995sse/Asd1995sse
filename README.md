## 🎮 Game Design & Modding

### SkyLandsForge — генератор парящих островов для Minecraft

[![Downloads](https://img.shields.io/badge/Downloads-3M+-blue?style=flat-square)](https://www.curseforge.com/minecraft/mc-mods/skylandsforge)
[![Versions](https://img.shields.io/badge/MC_Versions-1.7.10_|_1.10.2_|_1.12.2-green?style=flat-square)]()

Процедурный генератор мира, изначально создынный для режима **Sky Block Survival**, превращающий обычный ландшафт в архипелаг парящих островов. Но в последствие стал полноценным генератором мира, заменяя оригинальную генерацию мира.

**Что сделано:**
- 🏝️ **Процедурная генерация** — создание системы островов с настраиваемой плотностью и высотой
- ⚙️ **Гибкая конфигурация** — управление генерацией руд, деревень и параметров мира через конфиг
- 🔗 **Интеграция с Forge Ore Dictionary** — поддержка всех руд, зарегистрированных в системе
- 🌍 **Поддержка биомов** — совместимость с ExtrabiomesXL и Biomes O' Plenty
- ⚙️ **Гибкая конфигурация** — многопоточная генерация мира, предзагрузка чанков, доктор чанков(для лагающих чанков из-за модов).

**Стек:** Java, Minecraft Forge API, процедурная генерация, многопоточность, оптимизация
